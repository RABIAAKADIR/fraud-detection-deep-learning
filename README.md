# 🔍 Détection de Fraude Bancaire — Deep Learning

Modèle de détection de fraude sur données 
bancaires déséquilibrées.

## 🎯 Résultats
- AUC-ROC = **0.97** 🏆
- F1-score élevé sur classe minoritaire

## 🛠️ Approche
- Modèle LSTM (TensorFlow/Keras)
- Rééchantillonnage SMOTE
- Données déséquilibrées

## 💻 Technologies
- Python
- TensorFlow / Keras
- Scikit-learn
- Pandas / NumPy
